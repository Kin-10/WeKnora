# 前端工作台

入口 `/bid` 项目列表；项目内步骤：概览、招标解读、包段、要求、目录、本次事实、资料、正文、审查、导出。移动顺序根据项目状态提示，但支持回看与修订。沿用现有 Vue/TS/组件库/状态管理的真实约定，Phase 0 核验后落地。

正文页三栏：左侧目录及章节状态，中间富文本/表格/附件占位，右侧本章要求、已确认事实、资料来源和检查问题。编辑器可考虑 Tiptap，但先做格式和 AST 往返验证；复杂招标固定格式、合并单元格、页眉脚由导出层处理。

关键交互：来源点击可打开原件定位；确认事实展示影响章节；引用前展示主体/效期；生成时显示 job 进度与取消；版本冲突弹出差异；重新生成保留人工版；导出页显示阻断项、审查版本、导出文件版本。空/错/权限不足/解析失败状态均可恢复。

最小前端交付：项目 CRUD → 分包选择及要求确认 → 目录编辑 → 事实确认 → 单章生成/编辑/引用 → 审查 → 导出下载。前端仅调用已实现 API，不用 mock 结果宣称闭环完成。
