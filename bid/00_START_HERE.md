# WeKnora 标书工作台 · Codex 开发包

目标：在 `https://github.com/Kin-10/WeKnora` 的**指定提交**上，保留知识库、解析、检索及模型能力，新增以投标项目为中心的 Bid Workspace。先完成单项目、单包段、约十章节、人工复核、DOCX 导出的闭环，再扩展多包段与批量生成。

## 使用方法
1. 在本机克隆自己的 fork，记录 `git rev-parse HEAD`、上游提交、镜像摘要和当前依赖版本。不要直接假定本文提到的文件路径、接口或版本一定存在。
2. 把本压缩包的 `docs/bid/` 放入仓库，先给 Codex `08_CODEX_PROMPTS.md` 中的 Phase 0 提示词。
3. 检查它提交的实际架构映射、运行记录和差异清单，再按阶段逐个运行提示词；每阶段做人工验收和 git commit。
4. 若仓库实际情况与本包不同，更新设计记录后再实现，不能让 Codex 凭猜测新增平行基础设施。
