# DOCX 成册规范

单独的 bidwriter 接收版本化 Document AST、模板 ID、目录、章节、经过授权的附件文件引用、冻结来源清单。程序处理字体、样式、编号、表格、分页、页眉页脚、封面、目录字段、真实图片和附件；模型只负责正文草稿。

推荐 Python + python-docx/docxtpl/lxml 的独立服务，具体部署和调用方式由 Phase 0 确认。先实现一个稳定的模板，测试标题编号、中文字体、表格换页、图片清晰度、附件顺序和空章节。对于复杂 Word 模板和域更新，必要时使用 OOXML 与 LibreOffice headless 转 PDF 供预览；不能把 PDF 转换结果当 DOCX 完整性证明。

每次导出固定输入 revision，保存文件哈希、模板版本、章节/事实/来源版本清单及审查结果。导出任务须幂等；缺少实际附件文件时明确失败，绝不可插入伪造图片。打开生成 DOCX 进行结构检查并渲染抽样页面作人工视觉验收。
